CivicSuite module

CivicData Bridge

Open-data preparation for municipalities: normalize fields, draft dictionaries, prepare CKAN metadata, flag redaction review, and assemble retention-aware archive checklists.

v0.1.1 shipping

For staff

Use CivicData Bridge to prepare datasets before publication. Every dataset still needs human review, license confirmation, redaction/exemption clearance, and retention checks.

For IT

Install locally with python -m pip install -e ".[dev]" and run python -m uvicorn civicdata.main:app.

Boundaries

No live CKAN publication, BI dashboard, data warehouse, autonomous redaction, or connector runtime ships in v0.1.1.

Repository

CivicSuite/civicdata

Dependency

Pinned to civiccore==0.3.0. CivicCore remains dependency-only; it never imports CivicData Bridge.
